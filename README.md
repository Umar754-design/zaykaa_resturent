# Zayka Restaurant - Complete UI Design

A modern, responsive restaurant website built with React JS featuring a complete UI design for Zayka Restaurant.

## Features

- **Hero Section**: Eye-catching landing section with animated elements and key features
- **Interactive Menu**: Filterable menu with categories (Appetizers, Main Course, Vegetarian, Sides, Desserts, Drinks)
- **About Us**: Company story, statistics, and team member profiles
- **Contact Form**: Fully functional contact form with validation
- **Responsive Design**: Mobile-first approach that works on all devices
- **Modern UI**: Clean, professional design with smooth animations
- **Navigation**: Sticky header with mobile hamburger menu

## Installation

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start the Development Server**
   ```bash
   npm start
   ```

3. **Open in Browser**
   The application will open automatically at `http://localhost:3000`

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Launches the test runner

## Technologies Used

- **React 18.2.0** - UI library
- **React DOM 18.2.0** - React DOM renderer
- **React Scripts 5.0.1** - Build tooling
